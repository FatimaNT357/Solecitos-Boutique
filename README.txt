SOLECITOS BOUTIQUE - PROYECTO HTML Y CSS

Archivos principales:
- index.html: página principal
- login.html: página de acceso general
- productos.html: productos destacados
- inventario.html: panel de inventario
- ventas.html: panel de ventas
- css/estilos.css: hoja de estilos externa

Cómo abrir:
1. Extrae el archivo ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html con Live Server.
4. Usa el menú superior/lateral para navegar por las páginas.

Notas:
- Proyecto realizado con HTML y CSS, sin JavaScript, frameworks ni backend.
- Los formularios son visuales y no guardan ni envían información.
- Algunas fotografías se cargan desde URLs de Unsplash, por lo que requieren conexión a internet.
- Los datos de inventario y ventas son de ejemplo para la maqueta.
